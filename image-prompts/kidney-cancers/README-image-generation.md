# README — Image Generation Pack: Kidney Cancers

**Guide slug:** `kidney-cancers` · **Guide file:** `guides/kidney-cancers.html`

This pack contains 10 ready-to-paste image prompts (in `image-prompts/`) that
replace the guide's removed inline SVG diagrams with a unified, house-style set
of raster images.

## How to use this pack

1. Open each prompt file in `image-prompts/` in numeric order (001 → 010).
2. Copy its `COPY-READY IMAGE GENERATOR GPT PROMPT` block.
3. Paste it into the ChatGPT Image Generator GPT:
   **https://chatgpt.com/g/g-pmuQfob8d-image-generator**
4. Generate at the exact pixel dimensions listed for that image.
5. Save the result to `generated-images/[filename].png`.
6. Each image ships as a **`.png` + `.webp` pair**, and **both files go into the
   repo `/images/` folder** for Stage-2 wiring.

The guide HTML currently has matching `<!-- IMAGE PLACEHOLDER -->` comments at
each section, so Stage 2 can drop each image into its destination section.
