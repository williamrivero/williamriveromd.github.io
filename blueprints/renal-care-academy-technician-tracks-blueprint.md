# Renal Care Academy — technician tracks: curriculum blueprint and image plan

Handoff blueprint for Claude Code. Prepared November 23, 2026. Generated by `tools/techcourses/build_image_brief.py` from the `image_plan_*.py` files; edit those files and re-run instead of editing this document.

## 1. Goals and decisions

- Three technician tracks live in the Renal Care Academy (`/academy/`): Hemodialysis Technician (12 modules, built), Water Treatment System Technician, and Hemodialysis Center Biomedical Technician.
- **Decision in this blueprint:** the Water Treatment and Biomedical tracks grow from 6 to 12 modules each, matching the Hemodialysis Technician and Nephrology Nursing tracks. Existing modules are kept or split; three new modules are added to Water Treatment (2, 7, 11) and one to Biomedical (2), with new utilities content in Biomedical 11 and capstone stations in both Module 12s.
- Reading level stays at college level: every term explained at first use, glossary on every page, plain-words opener, and a figure for every idea that needs one.
- **Image plan:** 135 images: 100 core and 35 optional, including 26 heroes and 3 circuit figures. Each module gets a hero (Water Treatment and Biomedical), two core teaching figures, and one optional figure. Hemodialysis Technician heroes already exist; its figure A replaces each flat teaching diagram.
- Figures are GPT-rendered in the site's illustrated atlas style, never flat vector. Prompts follow Constitution v1.0 (seven layers, footer `© renalcarematters.com` specified three times; heroes carry no text). Circuit figures use the `dialysis-circuit-schematic` skill unchanged.
- Nothing is deployed without Dr. Rivero's sign-off.

## 2. Module format (unchanged)

Objectives → big picture in plain words (key terms) → opening case with questions → lesson parts with figures → case review → skills checklist with critical steps → self-assessment → reading. Question bank: 15 items per module for the Hemodialysis Technician track; raise the Water Treatment and Biomedical banks from 8 to 12 items when the modules are split. Draw 5 per visit.

## 4. Build instructions for Claude Code

1. **Split and write modules.** For each expanded track, create `tools/techcourses/<package>/m01.py … m12.py` from the module briefs above. Reuse the existing six module files: move sections to their new module as the Origin column states, then write the new sections. Keep the module schema, macros, and tuple formats already used. Update `MODULES` in each `course.py` (ids, slugs, titles, subs, `card_img`, `hero_brief`).
2. **Sources.** Keep limits and requirements tied to `shared.REFS` (ISO 23500 series, IEC 60601-1, IEC 60601-2-16, IEC 62353, WHO maintenance guidance, DOH AO 2012-0001, PSN 2024). Add references only after verifying them. State a number only when a cited source or the facility's own procedure supports it; otherwise say "per the manual" or "per unit procedure".
3. **Figures.** Add each produced image to `tools/techcourses/figs.py` (file, alt from the manifest, caption) and place it with `{{fig:key}}` in the section named in the manifest. Until an image exists, keep the current HTML flow strips and card grids in place so no page loses a figure.
4. **Slugs changed by the split.** Six Water Treatment and six Biomedical page addresses change. Nothing is live yet, so no redirects are needed; if the pages have been deployed by then, add `_redirects` entries from the old slugs.
5. **Rebuild.** `python3 tools/techcourses/build_image_brief.py`, `python3 tools/techcourses/prep_assets.py`, `python3 generate_tech_courses.py --patch`, `python3 tools/academy/wire_academy.py`, then the sitemap generator.
6. **Verify.** `generate_tech_courses.py --check`; every academy link resolves; figure numbers run in order; quiz draws and scores; trainer pages list all checklists; mobile and print layouts hold.
