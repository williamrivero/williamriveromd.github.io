| 1 | What is preventive maintenance? | Scheduled work done before failure occurs | It replaces wearing parts and checks performance on a schedule. |  |
| 2 | What does calibration mean? | Comparing a reading with a trusted reference and adjusting to match | Calibration ties the machine’s reading to a known value. |  |
| 3 | Why record the as-found value before adjusting? | It shows how far out the machine was, which may matter for patients already treated | A large as-found error is clinical information. |  |
| 4 | A reference meter is past its calibration due date. What is correct? | Do not use it until it is calibrated | An unverified reference can make every machine wrong in the same direction. |  |
| 5 | What does traceable mean for a reference instrument? | Its accuracy is linked by documented calibrations to a national or international standard | Traceability is the documented chain behind the instrument’s accuracy. |  |
| 6 | A reference meter is discovered to have been reading wrong. What must be reviewed? | Every machine it was used on since it was last known to be correct | All work done with a faulty reference is in doubt. |  |
| 7 | A center has ten machines with a six-month maintenance interval. About how many visits are needed per year? | 20 | Ten machines, twice a year each, is twenty visits. |  |
| 8 | Which item belongs in every service record? | The identity and calibration due date of the test instruments used | Without the instrument’s identity, the measurements cannot be traced. |  |

## Module 5: Disinfection, Descaling, and Electrical Safety Testing

| Q | Stem | Keyed answer | Explanation | Objective |
|---|---|---|---|---|
| 1 | What is scale inside a dialysis machine mostly made of? | Calcium carbonate from bicarbonate dialysate | Calcium and magnesium combine with bicarbonate to form a hard crust. |  |
| 2 | Which agent removes scale? | An acid such as citric acid | Acid dissolves carbonate scale; bleach does not. |  |
| 3 | Why must bleach and acid programs never be run back to back without rinsing? | They release chlorine gas | The mixture releases toxic chlorine gas. |  |
| 4 | What does a residual test show? | That no disinfectant remains after rinsing | It protects the patient from chemical remaining in the fluid path. |  |
| 5 | Residual test strips have run out. What is correct? | Do not use the machine until a residual test is negative | Without a valid test there is no proof the chemical is gone. |  |
| 6 | What is the purpose of the protective earth connection? | To carry fault current safely away from the case | It prevents the case from becoming live if insulation fails. |  |
| 7 | When is an electrical safety test required apart from the scheduled interval? | After repairs affecting electrical safety, or after the machine is dropped or flooded | Any event that could affect insulation or earthing calls for a retest. |  |
| 8 | Why are dialysis patients especially vulnerable to small electrical currents? | They are connected to the machine by conductive blood and saline, sometimes through a catheter near the heart | A direct conductive path makes very small currents hazardous. |  |

## Module 6: Troubleshooting, Records, and Return to Service

| Q | Stem | Keyed answer | Explanation | Objective |
|---|---|---|---|---|
| 1 | Three machines fed by the same concentrate line alarm for low conductivity within minutes. What is the most likely cause? | A problem with the shared concentrate supply | Simultaneous faults on several machines point to something they share. |  |
| 2 | What is the first step in fault-finding? | Gather the exact alarm text and the circumstances | Facts first; they often identify the cause without opening the machine. |  |
| 3 | Why check simple causes first? | They are commonly the cause, and it avoids disturbing a healthy machine | Supplies, connections, water, and settings account for many alarms. |  |
| 4 | A part was replaced and the alarm stopped, but the reason the part failed is unknown. What is true? | The diagnosis is incomplete and the fault may return | Without a cause, the same failure may recur. |  |
| 5 | The fluid path was opened during a repair. What is required before release? | Disinfection and a negative residual test, plus the manual’s verification tests | Opening the fluid path can introduce contamination. |  |
| 6 | A required post-repair test cannot be completed before the next shift. What is correct? | Keep it out of service and state when it will be ready | A machine is released only when every required test has passed. |  |
| 7 | Who accepts a repaired machine for clinical use? | The charge nurse, after the technician’s handover | The technician certifies technical fitness; the clinical lead accepts it for use. |  |
| 8 | Which indicator should always be zero? | Test instruments in use past their calibration due date | An overdue instrument undermines every measurement made with it. |  |
