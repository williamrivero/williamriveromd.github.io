Every prompt in a gray block is complete on its own.

## How to produce

1. **One figure per chat.** Paste one prompt into a fresh ChatGPT image chat and ask for the canvas size on the entry.
2. **No attachments.** No figure in this addendum needs an attached reference image. The one circuit-style figure (13-M, plasma separation) uses the house port rules written into its prompt.
3. **Check every label** against the verbatim label list in the prompt; ask for a one-word fix rather than regenerating when a single word is wrong.
4. **Run the QA list.** Reject any image with an invented number, dose, alarm limit, or device setting; a dark background; a missing or altered footer (`© renalcarematters.com`); a wrong circuit connection; or, in the heroes, any text at all.
5. **Clinical review.** Entries with reviewer flags need your check before publishing. Pay particular attention to 14-B (screening and crisis pathway), 16-D (requests to stop dialysis), 15-D (immunosuppressant watch-list), 11-D (pregnancy on dialysis), and 13-N (plasma exchange reactions).
6. **Save** under the exact filename on each entry (PNG) into the same `Module images` folder as before.
7. **Dense figures.** If 09-D (drug timing), 09-E (monthly panel), or 17-C (icon arrays) garbles after two tries, say so; each has an HTML table on the page that can carry the content instead.
8. **Heroes.** The module files name the heroes by work ID (`renal-nursing-14-living-well`, `renal-nursing-15-glomerular`, `renal-nursing-16-palliative`, `renal-nursing-17-teaching`). The saved file uses the site convention `<page-slug>-vignette-hero.png`, exactly as the first brief did; both names are given on each hero entry.

## Standing rules (already written into every prompt)

- Light background; Inter font; navy #0f1e2e text, teal #1a6b72 accent, renal green #1f7a4d for "report" or "safe" endpoints, caution amber #b8860b for warnings, soft gray #f3f4f6 card fills. Circuit colors (13-M only): arterial red #C00000, venous blue #1F6FC0, replacement green #2E6B3E, plasma and effluent teal #1A6B72, citrate amber #C9A84C.
- Footer `© renalcarematters.com`, bottom right, small, semi-transparent navy, on every figure except the heroes (no text at all).
- American English in every rendered word. Plain-language labels; a medical term appears only with a plain gloss beside it.
- Numbers only as the lesson states them; no doses, rates, targets, thresholds, alarm limits, or device settings ("per order", "per unit protocol").
- People: Filipino patients, families, and nurses of varied ages, builds, skin tones, and sexes, shown with dignity; no real people, brands, logos, or copyrighted characters. Module 16 imagery is calm and dignified, with no death imagery.
